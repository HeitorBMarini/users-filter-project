## 📝 Descrição
Este projeto foi desenvolvido utilizando **Angular** e **TailwindCSS** para criar um sistema de **filtro de usuários**, onde é possível:
- 🔍 Filtrar usuários por **nome, data de cadastro e status**.
- 📌 Selecionar um usuário para visualizar detalhes em um **sidebar interativo**.
- 🎨 Utilizar **TailwindCSS** para estilização moderna e responsiva.

## 🛠️ Tecnologias Utilizadas
- **Angular** ⚡ (Framework frontend)
- **TailwindCSS** 🎨 (Estilização responsiva)
- **TypeScript** 📌 (Tipagem e segurança)
- **Pipes personalizados** 🔥 (Para formatação de dados)
